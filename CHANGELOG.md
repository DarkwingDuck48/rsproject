## [0.1.1] — 2026-09-15

### Добавлено

- Шаблоны для GitHub: bug report, feature request, pull request
- Руководство для участников (`CONTRIBUTING.md`)
- Кодекс поведения (`CODE_OF_CONDUCT.md`) — Contributor Covenant 2.0
- Конфигурация шаблонов issues (`config.yml`) — запрет пустых issues
- Добавлен CHANGELOG.md
- Добавлено окно About (О программе)
- Полный переезд графического интерфейса с EGui на Tauri v2 + React 19 (JavaScript) + Vite
- UI-библиотека Ant Design v6, даты на dayjs
- Вкладки «Проект», «Задачи», «Ресурсы» и «Диаграмма Ганта» с боковой панелью и статус-баром
- Создание, редактирование, открытие и сохранение проектов в JSON через системные диалоги
- Задачи: CRUD, иерархия (сводные задачи), зависимости с лагом, назначение ресурсов с проверкой доступности
- Ресурсы: CRUD, периоды недоступности, проверка доступности
- Диаграмма Ганта на SVG: полосы задач, стрелки зависимостей, подсветка критического пути, тултипы, горизонтальный скролл
- Темизация: светлая/тёмная тема с сохранением выбора
- Горячие клавиши: `Ctrl/Cmd+N/S/O` (проекты), `Delete` (удаление выделенного)
- Статус-бар: количество задач/ресурсов, длительность критического пути, дата сохранения
- Синхронизация выделения задач/ресурсов между боковой панелью и таблицами
- Адаптивный ресайзинг окна (минимум 640×480)
- Демо-проекты: `demo_project` (9 задач) и `big_project` для быстрой проверки через «Файл → Открыть проект»

### Изменено

- Интерфейс полностью переписан: EGui → Tauri v2 + React 19

### Удалено

- Старый EGui-код (`app_egui_old/`) и зависимости `eframe`/`egui`/`rfd`

## [0.1.0] — 2025-07-04

### Добавлено

- Отображение зависимостей между задачами в интерфейсе (#16)
- Редактирование зависимостей задач
- Лицензия Apache 2.0 (`LICENSE`)
- README: описание проекта, скриншоты интерфейса, инструкции по сборке

### Изменено

- Обновлён CI/CD: убраны суффиксы `amd64` из названий артефактов сборки

## [0.0.1] — 2025-02-22

### Добавлено

- Первая предварительная версия (`v0.0.1`)
- Создание и редактирование проектов
- Управление задачами с иерархией (групповые задачи)
- Управление ресурсами
- Назначение ресурсов с проверкой доступности
- Расчёт критического пути проекта
- Диаграмма Ганта с подсветкой критического пути
- Сохранение и загрузка проекта в формате JSON
- Базовый пользовательский интерфейс (egui/eframe)
- CI: автоматическая сборка и тестирование (`ci.yml`)
- CD: автоматическая публикация релизов (`release.yml`)
